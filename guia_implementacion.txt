## 1. PREPARAR EL SISTEMA HOST

### Instalar LXD (si no esta instalado)
```
sudo apt-get update
sudo apt-get install -y snapd
sudo snap install lxd
sudo lxd init --auto
```

## 2. CONFIGURAR CONTENEDOR LXD

### Crear y configurar el contenedor
```
# Crear el contenedor usando Ubuntu 24.04 LTS minimal
sudo lxc launch ubuntu:24.04 vm-management -c limits.cpu=2 -c limits.memory=2GB

# Acceder al contenedor
sudo lxc exec vm-management -- bash

# Actualizar el sistema dentro del contenedor
apt-get update
apt-get upgrade -y
```

## 4. CONFIGURAR POSTGRESQL

### Iniciar y configurar PostgreSQL
```
# Iniciar servicio PostgreSQL
systemctl start postgresql
systemctl enable postgresql

# Cambiar al usuario postgres
su - postgres

# Crear usuario de base de datos
psql -c "CREATE USER vmadmin WITH PASSWORD 'SecurePassword123';"

# Crear base de datos
psql -c "CREATE DATABASE vmmanagement;"

# Otorgar privilegios
psql -c "GRANT ALL PRIVILEGES ON DATABASE vmmanagement TO vmadmin;"

# Configurar acceso (opcional para entornos de desarrollo)
echo "local all vmadmin md5" >> /etc/postgresql/*/main/pg_hba.conf

# Volver al usuario root
exit

# Reiniciar PostgreSQL para aplicar cambios
systemctl restart postgresql
```

## 7. CONFIGURAR APACHE

### Configurar el sitio web en Apache
```
# Crear archivo de configuracion de Apache
vim /etc/apache2/sites-available/vmmanagement.conf
```

Contenido del archivo vmmanagement.conf:
```apache
<VirtualHost *:80>
    ServerName vm.example.com
    ServerAdmin webmaster@example.com

    DocumentRoot /var/www/vmmanagement

    # Configuracion WSGI
    WSGIDaemonProcess vmmanagement python-home=/var/www/vmmanagement/venv python-path=/var/www/vmmanagement
    WSGIProcessGroup vmmanagement
    WSGIScriptAlias / /var/www/vmmanagement/wsgi.py

    <Directory /var/www/vmmanagement>
        WSGIProcessGroup vmmanagement
        WSGIApplicationGroup %{GLOBAL}
        Require all granted
    </Directory>

    # Archivos estaticos
    Alias /static/ /var/www/vmmanagement/app/static/
    <Directory /var/www/vmmanagement/app/static/>
        Require all granted
    </Directory>

    # Logs
    ErrorLog ${APACHE_LOG_DIR}/vmmanagement-error.log
    CustomLog ${APACHE_LOG_DIR}/vmmanagement-access.log combined
</VirtualHost>
```

### Crear archivo WSGI
```
# Crear archivo wsgi.py
vim /var/www/vmmanagement/wsgi.py
```

Contenido del archivo wsgi.py:
```python
import sys
import os

# Agregar el directorio de la aplicacion al path
sys.path.insert(0, '/var/www/vmmanagement')
sys.path.insert(0, '/var/www/vmmanagement/app')

# Activar el entorno virtual
activate_this = '/var/www/vmmanagement/venv/bin/activate_this.py'
with open(activate_this) as file_:
    exec(file_.read(), dict(__file__=activate_this))

# Importar la aplicacion
from app import app as application
```

## 10. SEGURIDAD Y MANTENIMIENTO

### Configurar copias de seguridad
```
# Crear script de backup
vim /usr/local/bin/backup-vmmanagement.sh
```

Contenido del script de backup:
```bash
#!/bin/bash
DATE=$(date +%Y-%m-%d_%H-%M-%S)
BACKUP_DIR="/backup/vmmanagement"

# Crear directorio si no existe
mkdir -p $BACKUP_DIR

# Backup de la base de datos
su - postgres -c "pg_dump vmmanagement" > $BACKUP_DIR/db_$DATE.sql

# Backup de archivos
tar -czf $BACKUP_DIR/files_$DATE.tar.gz /var/www/vmmanagement

# Eliminar backups antiguos (mantener solo los ultimos 7 dias)
find $BACKUP_DIR -name "*.sql" -mtime +7 -delete
find $BACKUP_DIR -name "*.tar.gz" -mtime +7 -delete
```

```
# Dar permisos de ejecucion
chmod +x /usr/local/bin/backup-vmmanagement.sh

# Programar backup diario
echo "0 2 * * * root /usr/local/bin/backup-vmmanagement.sh" > /etc/cron.d/backup-vmmanagement
```

## NOTAS IMPORTANTES

1. Mantener actualizadas las credenciales y claves secretas
2. Actualizar regularmente el sistema operativo con apt-get update y apt-get upgrade
3. Monitorear los logs de Apache y PostgreSQL para detectar problemas
4. Realizar backups regulares de la base de datos y archivos
5. Considerar configurar HTTPS con certbot para proteger el trafico

## RESOLUCION DE PROBLEMAS

### Si el sitio no carga
- Verificar logs: `tail -f /var/log/apache2/vmmanagement-error.log`
- Comprobar permisos: `ls -la /var/www/vmmanagement/`
- Verificar estado de Apache: `systemctl status apache2`

### Si hay problemas con la base de datos
- Verificar la conexion: `sudo -u postgres psql -c "\l"`
- Comprobar que PostgreSQL esta funcionando: `systemctl status postgresql`
- Verificar la cadena de conexion en config.py
